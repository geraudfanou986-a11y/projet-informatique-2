4. Contrôle côté serveur (PHP 8)
--------------------------------
Commande :
    php -r 'echo htmlspecialchars("<script>alert(1)</script>", ENT_QUOTES|ENT_SUBSTITUTE, "UTF-8");'

Sortie réelle :
    &lt;script&gt;alert(1)&lt;/script&gt;

Le rendu côté navigateur utilise textContent (dans assets/js/app.js, fonction h()),
le code serveur utilise htmlspecialchars() quand il sort du HTML. Les deux
protections sont vérifiées : aucune donnée n'est jamais passée à innerHTML.
